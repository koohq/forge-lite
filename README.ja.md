## 概要

**Forge Lite** は、「手塩にかけて鍛え上げた装備で難関を突破する」爽快感を追求した、ピュア Go 製の CUI ローグライトゲームです。

- **外部依存ゼロ**: サードパーティの重厚な TUI フレームワークや CGo を一切使わず、Go 標準ライブラリ（`fmt`, `bufio`, `embed` など）のみで高速・軽快に動作。
- **インフレ体験**: 武器の強化値（+値）が百、千の領域に到達するにつれ、与ダメージが劇的に跳ね上がります。
- **安心のオート戦闘**: ターン制コマンド入力を自動化。HP が 30% 以下になると自動で停止し、プレイヤーに操作を返還する安全設計。
- **テーマ切り替え機能**: 王道ファンタジー、サイバーパンク、バディSF などの組み込みテーマを即座に切り替え可能。さらに自作の JSON によるカスタムテーマにも対応。

## 必要要件

- **Go**: `1.27.1` 以上
- **Task** ([go-task](https://taskfile.dev)): 任意（ビルドや実行コマンドの短縮に使用）

## クイックスタート

### 実行

ソースコードから直接起動します:

```bash
# Task を使用する場合
task run

# Go コマンドを直接使用する場合
go run ./cmd/game
```

### ビルド

現在の OS 向けのバイナリを `bin/game`（Windows では `bin/game.exe`）に出力します:

```bash
# Task を使用する場合
task build

# Go コマンドを直接使用する場合
mkdir -p bin
go build -o bin/game ./cmd/game
```

### クロスコンパイル

Windows, Linux, macOS 向けのバイナリを一括でクロスコンパイルします:

```bash
task build:all
```

出力先:
- `bin/game-windows-amd64.exe` (Windows amd64)
- `bin/game-linux-amd64` (Linux amd64)
- `bin/game-darwin-arm64` (macOS arm64)

### Go によるインストール

`$GOPATH/bin` へ最新バージョンを直接インストールします:

```bash
go install github.com/<username>/<repo>/cmd/game@latest
```

## ゲームシステム

### ダンジョン一覧

1. **始まりの洞窟 (5F)**: 初級ダンジョン。序盤の強化の書集めや、基本的なオーブの獲得に適しています。
2. **灼熱の深層 (10F)**: 中級ダンジョン。強力な敵が出現し、より多くの戦利品を持ち帰ることができます。
3. **無限の深淵 (エンドレス)**: 階層無制限の最難関。敵のステータスが段階的に強化されます。最高到達階層に応じて、10階刻みでのスキップ出撃が可能です。

> **リスクとリターン**: 階層突破時や戦闘中に「撤退」またはダンジョンをクリアすると、道中で獲得した強化の書やオーブを無事に拠点へ持ち帰ることができます。力尽きた場合、その回の戦利品は全ロストしますが、育てた武器の強化値、最大HP、最高到達階層は永続的に保持されます。

### 拠点および快適機能 (QoL)

- **オート戦闘**: テンポよく敵と交戦します。HP が 30% 以下になるか危険域に達すると即座に停止し、手動入力へ安全に切り替わります。
- **多彩な強化オプション**:
  - **通常強化**: 強化の書 1 枚を消費して武器を強化 (+1)。
  - **数値指定強化**: 指定した回数または目標の +値 まで一括で強化。
  - **一括強化**: 所持している強化の書をすべて投入して一気に限界まで強化。
- **オーブ（印）の管理と合成**:
  - **装着**: 武器のスロット（最大3枠）にオーブを装着し、特殊効果（連続攻撃、会心の一撃、ドレイン、毒など）を付与。
  - **一括分解**: 倉庫にある未装着のオーブをまとめて「強化の書」へ分解。
  - **上位合成**: 同種の通常オーブ 2 個を合成し、強力な上位オーブ（`+` 付き）を精製。
- **体力強化**: 強化の書を消費して、プレイヤーの最大HPを底上げ。

## プリセットテーマ

本ゲームには、完全バイリンガル（日本語・英語）対応の 3 つのテーマが標準搭載されています:

- 🗡️ **Classic Fantasy**: 鍛冶屋で装備を鍛えてダンジョンに挑む、王道ファンタジーRPG。
- ⚡ **Cyberpunk**: パルスブレードのオーバークロックと電脳網ハッキングをテーマにした SF 世界観。
- 🤖 **Partner Sync**: 戦術アンドロイド「アイリス」とデータリンクを同期し、連携訓練を重ねる共闘バディ。

テーマはゲーム内の **設定 (Settings)** メニューからいつでも切り替えることができます。

## カスタムテーマ

武器名、ダンジョン名、敵の呼称、オーブの名称・効果説明、拠点メニューの文言など、ゲーム内のすべてのテキストを JSON ファイル 1 つで自由にカスタマイズ可能です。

### カスタムテーマの利用手順

1. **雛形の出力**: ゲーム内の **設定 (Settings)** メニューから「雛形出力 (Export Custom Theme Template)」を実行すると、カレントディレクトリに `custom_theme.json` が生成されます。
   - または、リポジトリに含まれるサンプルファイルをコピーして作成することもできます:
     ```bash
     cp custom_theme.example.json custom_theme.json
     ```
2. **`custom_theme.json` の編集**: 武器名やメッセージをお好みの設定・ストーリー・言語に書き換えます。
3. **最優先読み込み**: カレントディレクトリに `custom_theme.json` が存在する場合、起動時にプリセットよりも優先して最優先で自動ロードされます。
